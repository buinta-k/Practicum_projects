  Планировщик задач

Веб-приложение на Go для создания, просмотра, изменения и удаления задач. Поддерживает повторение задач по дням, неделям и месяцам, а также поиск по заголовку, комментарию и дате.

  Стек технологий:
Go, SQLite, HTML, CSS, JavaScript, Docker

  Реализованные возможности:
- CRUD-операции с задачами.
- Расчёт следующих дат выполнения повторяющихся задач.
- Поиск задач по заголовку, комментарию и дате.
- Аутентификация с использованием токена.
- Настройка порта, пароля и пути к базе через переменные окружения.

Запуск: настройте переменные окружения в PowerShell:

$env:TODO_PORT="7540"
$env:TODO_PASSWORD="12345"
$env:TODO_DBFILE="./scheduler.db"
go run .

Приложение будет доступно по адресу http://localhost:7540.

  Запуск тестов:

go test ./tests

Запуск через Docker

docker build -t my-todo-app .
docker run -d -p 7540:7540 -e TODO_PASSWORD="12345" -e TODO_DBFILE="/app/scheduler.db" -v "${PWD}\scheduler.db:/app/scheduler.db" my-todo-app

  Реализован планировщик задач с поддержкой повторений, поиска и аутентификации. Выполнены дополнительные задания со звёздочкой.
