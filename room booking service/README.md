Бронирование комнат
REST API на Go для управления комнатами и бронированиями. Позволяет создавать комнаты, бронировать их на определённые даты, отменять брони и искать свободные комнаты. Дополнительно реализован веб-интерфейс с календарём занятости.
Стек технологий
- Go 1.26, net/http
- SQLite (modernc.org/sqlite)
- HTML, CSS, JavaScript
Запуск
Требуется Go 1.26 или совместимая версия.
git clone <ссылка-на-репозиторий>
cd <папка-проекта>
go run .
После запуска откройте http://localhost:3000.

База данных demo.db создаётся автоматически при первом запуске. Запускать приложение нужно из корня проекта.
Основные решения
- Проверка пересечения периодов бронирования.
- Создание брони и проверка доступности комнаты в одной транзакции.
- Отмена брони через мягкое удаление.
- Поиск свободных комнат с помощью SQL-запроса NOT EXISTS.
Результат
Реализовано приложение для бронирования комнат с REST API, проверкой занятости и веб-интерфейсом.
